## Limits

- **Cold public code.** A control here is a commit at least six months old whose added lines no
  later commit has touched. That population is biased toward quiet code, so a low publication
  rate on it is weaker evidence than the same rate on live traffic.
- **The seven are all `urllib3`.** The driver walks the population in a fixed order and the tail
  of that order is one repository. n = 7 is not seven independent projects.
- **Mixed discriminators.** The 58 did not run under one rule, so "58 controls, 2 wrong
  publications" is a fact about the project's history and not a rate for any single version.
