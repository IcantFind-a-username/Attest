## 2. The honest reading of 42.9%

**This population yields no usable bound and none is claimed.** The reason is not the stop and
not the publication — it is that **57 of the 68 controls produced no candidate at all**, and only
12 bought a reproduction. A control the model says nothing about cannot demonstrate that the
rule declines to publish; it only demonstrates that discovery was silent. The denominator that a
null study needs is *controls where publication was possible*, and this population supplies 7.

D-134's **5.2%** on the first 58-control population therefore remains the only bound
`G-NULL-001a` has, with its caveat intact: it was taken on the controls the intent rule was
revised against. The independent population's contribution is different and still worth its
$1.25 — **zero wrong publications in 68 independent controls, one of which was not a control at
all**, and the finding that the control definition, not the certification path, is what this
corpus is now testing.

## 4. The stop rule that let this finish (D-141)

A control that publishes stops the run. It may only resume after an **independent probe** — a
minimal reproduction transcribed from the two revisions, carrying **no product code**, run on
**at least two Python versions** — shows the defect is real. Then the control is recorded as
`true_positive_on_control`, kept out of the wrong-publication count, and the run continues; a
probe that shows nothing leaves the run stopped for root cause. The adjudication lives in the
driver (`ADJUDICATED`), names its probe and its interpreters, and a publication that is not in
that table stops the run — silence is a stop, never a pass.

Two Python versions is the rule's content rather than ceremony, and this very case shows why:
the `divide()` defect is **invisible on 3.11 and present on 3.12**, so a one-interpreter probe
would have adjudicated it either way by accident.

## 5. The population is closed (D-144)

**No further control is added to this population, and the number it reports is
`answered n = 7, 0 wrong, 1 true positive on a control`.** The bound is stated only to be
refused: 3/7 = 42.9% is what the rule of three returns and it is not a bound anyone should
quote.

The arithmetic that closes it. 68 controls cost **$1.2543**, or **$0.0184** each, and produced
**7** answered ones — a yield of **10.3%**. `G-NULL-001` asks for ≤1% wrong at 95% confidence,
which needs **n ≥ 300 answered**. At this corpus's yield that is about **2,900 more controls**
and **~$53** — more than the $34 that remains under the $90 cap, and more than this window's
whole allowance. Buying 300 *reviewed* controls instead would cost ~$5.50 and return about 31
answered ones, which is a 9.7% bound: better than 42.9%, still not a gate.

**So the gap is not money at this cap; it is the population.** The binding constraint is that
**57 of 68 qualified null commits produce no candidate**, and no amount of the same sampling
changes that ratio. A population that could answer would have to be *selected for producing
candidates* — which is no longer a null study, because the selection is made by the thing under
test. Recording that as the reason is the useful output of this run.

What stands after the closure:

- **D-134's 5.2% at n = 58** remains the only bound `G-NULL-001a` has, with its caveat: it was
  taken on the controls the intent rule was revised against, so it is a regression test as much
  as a null study.
- **0 wrong publications in 68 independent controls** is a fact of this population and is
  reported as a count, never as a rate.
- **1 true positive on a control** is the finding this population actually bought, and it cost
  the control definition its credibility rather than the certification path.
