# Attest v2 validation fixtures

The normative receipt rules are in [`protocol.md`](protocol.md). The executable
constructed fixture is generated by
[`tests/benchmark/_validation_v2.py`](../../tests/benchmark/_validation_v2.py)
so every test gets fresh artifact bytes and can mutate one field without
rewriting a committed evidence record.

This directory contains no empirical result. The historical v1 receipt and
validation results remain byte-for-byte unchanged.
