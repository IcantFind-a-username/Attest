# Natural-pair original-human-test witness

This free, bounded development diagnostic follows D-279 under the owner's
compatibility authorization. Baseline 4be26b5. It does not amend D-276's failed
qualification, source freeze, sample minimum or paid protocol. No new candidates
or controls are selected. Retain both original source pairs and all refusals.

## Inputs and fixed method

Commit `scripts/corpus/natural_pair_original_tests.py` and this protocol before
execution; obtain one independent review first. Bind cases.json via natural_cases,
the raw terminal runtime record via the committed manifest digest, the complete
ordered four runtime revisions, committed build evidence, and the original oracle
manifest/payload digests. Run only pairs with both sides runtime-ready and identical
runtime dependency freeze bytes. The scikit-learn pair remains runtime-unqualified.
No build, environment modification, alternate dependency recipe or repair retry.

Support exactly one upstream module-level FAIL_TO_PASS node and one existing test
file plus one production Python anchor from the original patch metadata. Other
shapes refuse; no hand-written replacement test. Reconstruct the entire original
test module by reading its original SWE-bench base blob and applying only the
original test_patch. Copy those identical resulting test bytes into fresh exports
of the natural parent and introducing head. This is a test-only overlay; the
production repair patch is never applied. Preserve the original test body/imports,
node identity and test-file digest. A future test-module context that cannot run
on the historical parent remains unqualified, not rewritten.

Reuse archive, strict revision-specific wheel transfer and execute_repro's existing
in-tree target support. Refuse tracked symlinks before export. Each side gets its
own already-built wheel and digest-bound runtime image. No source or conftest edit,
extra plugin, source-generation model or new execution mechanism. Container and
language guards remain enabled; project addopts are cleared by the gated D-278
executor. The original test is the target, not the duplicate generated input file.

Three fixed pairs, parent then head per repeat, fresh nonced execution each time;
120-second wall/CPU bounds, 2 GiB memory and bounded output. A pair must yield the
same exact upstream JUnit node, one test, zero errors/skips/xfails, parent exit 0
and NOT_REPRODUCED, head exit 1 and REPRODUCED. Require the network guard, fresh
state, actual traced lines in the mounted anchored source, no mismatched anchor
import origins, and unchanged test bytes after every run. These trace checks bind
execution location, not semantic correctness; the earlier two independent source
reviews supply the bounded semantic judgment. If either side does not match, retain
both outcomes and stop the case without retries or changing tests/settings.

## Reporting

Keep raw original tests, execution observations and artifacts in a mode-0700
corpus directory. Publish bounded safe outcome metadata, identities/digests and
failure category; do not commit oracle source or full failure traces. Count source
cases rather than six executions. A successful pair is a development original-test
witness, not a product receipt, recall or precision result. Record zero product
reviews, zero paid calls and unchanged paid qualified counts. A compatible single
case cannot satisfy three defects across two repositories or replace independently
qualified reasonable-change controls. Default v5.1, certification, publication
policy, cumulative spend cap, remote state and release status remain unchanged.
